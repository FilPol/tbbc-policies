Privacy Policy — tbbc uploader

Last updated: 24 October 2026

Data collected

The "tbbc uploader" app is a personal, single-user automation tool. It:

  • Uses an OAuth 2.0 access token to post videos to the developer's own TikTok

    • account via the official TikTok for Developers Content Posting API.

  • Stores the OAuth client key/secret and access token only on the owner's own

    • private server, accessible only to the owner.

  • Does NOT collect, store, or process any data from TikTok users, viewers, or

    • any third party. No analytics, no tracking, no advertising.

    Data shared

    No personal data is shared with any third party. The only external service

    contacted is TikTok's official API, for the purpose of publishing the owner's

    own content.

    Your rights

    Since no personal data of any user is collected, there is no data to access,

    correct, or delete.

    Contact

    Questions about this policy can be directed to the developer account on

    developers.tiktok.com (app: tbbc uploader).
